# 👁️ Eye of Providence

Uma skill para o [Claude Code](https://claude.com/claude-code): o olho que tudo vê.

Ela faz o Claude **abrir e usar de verdade** o seu projeto (site, app ou programa), clicar em todos os botões, caçar bugs, lentidão e melhorias, e corrigir tudo como uma "versão 2.0", sem renomear nada.

## Instalação

Copie a pasta `eye-of-providence` para a pasta de skills:

```bash
git clone https://github.com/<seu-usuario>/eye-of-providence.git
cp -r eye-of-providence/eye-of-providence ~/.claude/skills/
```

## Uso

No Claude Code, dentro do projeto:

> usa a skill Eye of Providence e dá uma olhada geral

## O que ela faz

- Entende o conceito do projeto antes de mexer.
- Roda o projeto e testa tudo na prática: nada de "rodei e não deu erro".
- Caça bugs, erros, lentidão, código frágil e problemas de segurança.
- Corrige pela ordem de gravidade e testa de novo depois de cada correção.
- Usa uma checklist com 20 itens extras: Lighthouse, celular/tablet, internet lenta, links quebrados, vazamento de memória, nota de 0 a 10 por área e outros.
